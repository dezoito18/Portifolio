# 💻 Portfolio | Matheus

My personal portfolio built with **HTML, CSS and JavaScript**, featuring a cyberpunk look in purple, cyan and yellow tones. It presents who I am, my projects and how to get in touch.

🔗 **Live site:** https://dezoito18.github.io

---

## ✨ Features

- **About**, **Projects** and **Contact** sections
- Project cards **generated dynamically with JavaScript**
- **Technology filter** (All, C, HTML/CSS)
- Technology icons on each project card
- Anchor navigation that scrolls to each section
- Neon glow effects and smooth transitions

---

## 🛠️ Technologies

- **HTML5**: page structure
- **CSS3**: styling, Flexbox, Grid and visual effects
- **JavaScript**: project cards and filtering
